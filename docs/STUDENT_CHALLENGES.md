# Student Challenges

The **Progressive student challenges** tab reveals feedback only after you submit a selection or response.

1. **Evidence or assumption?** Classify the claim that an employee was phished from the email-receipt observation.
2. **Find the ATT&CK mapping:** Assess a PowerShell child process against the curated v15.1 catalogue and explain the limits of the evidence.
3. **Identify missing evidence:** Select telemetry that could attribute a network transfer and characterize the data.
4. **Build the investigation map:** Add evidence-linked candidate mappings, rationale, alternatives, missing evidence, and status. Matrix grouping is not a timeline.
5. **Defend your conclusion:** Separate an observation, a hypothesis, an unresolved issue, and a next step.

Use the mapping page and hypothesis worksheet while completing the challenges. A technically correct ID without evidence and reasoning is not a defensible analysis.
